# Fonts

Still uses **Figtree** (SIL Open Font License, see `OFL.txt`). The font is served from this folder, so no visitor data goes to Google.

- `Figtree-Variable.woff2`: the variable font (weights 300–900, Latin), taken from `@fontsource-variable/figtree`.
- The Expo app can't load files from this folder, so it uses a copy embedded in `mobile/components/figtree-font.css`. If you replace the font here, regenerate that file too.
